Unreal Engine project files for the Dynamic Voice Chat plugin demo project.

This requires the plugin to be installed to the engine. If you do not own the plugin yet you can try out the pre packaged builds from [Google Drive](https://drive.google.com/drive/folders/1Bph92iFsUfEKxlwhfLj5p8xCMXCN5BzN?usp=sharing).

[Link to Dynamic Voice Chat System on Fab.com](https://www.fab.com/listings/78769f70-76a5-4cfd-bac0-1fed7f99381a)

To use this project follow these steps:
1. Make sure you have the plugin installed for your engine version.
2. Make sure you have Visual Studio installed.
3. Download or clone this Git repo.
4. Right click the uproject file and select "Generate Visual Studio Project Files" or select "Switch Unreal Engine Version" to select your UE version (5.4+).
5. Open the generated .sln and compile the project.
6. Double click the uproject and you are good to go.
